# ADR 0003: Make the one-city rehearsal the first runtime acceptance boundary

- **Status:** accepted
- **Date:** 2026-08-05

## Context

The project needs one complete, human-visible path before it can safely add
second-city exchange or municipal authority. Starting with a live city system
would make an incomplete coordination path look like a legal or civic action.

## Decision

The first runtime acceptance boundary is a disposable, restartable one-city
rehearsal. It covers signed discussion, suggestion, administrative review,
reviewed citizen information, advisory participation, and a council rehearsal;
none of these steps is a formal proposal, legal submission, publication, vote,
authority transition, or civic-state mutation. Paid providers, public
federation, and a second city remain outside this boundary until the one-city
path is replayable, redacted, and deletable.

## Why

This gives the team a concrete end-to-end proof while keeping the authority
boundary explicit. A disposable rehearsal can be replaced or deleted without
claiming that a suggestion, forecast, or advisory result changed a city's
official record.

## Consequences

The team must complete and accept the one-city L2 evidence gate before adding
cross-city federation or any formal city-system transition. Local proof may
inform that gate but cannot be reported as a live deployment.
