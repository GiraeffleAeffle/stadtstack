02

Roles and boundaries

What each project owns

Three contributors, three seams, one shared contract. The boundaries matter more than a shared database.

Röbel App owns the public community experience: ordinary posts, signed Discussions, Topics, the one Civic Journey view, Public Mecky, and the Mitmachen rendering.

Stadtstack owns municipality-neutral Civic case contracts, Human Case admission, review-gated projections, Department packages, and the durable continuation line. It does not own a city's source records, legal authority, formal vote, or treasury.

Reviewed public sources remain one seam with explicit child kinds. City-specific Adapters capture exact OParl/RIS official records and local reporting without conflating them; a human Reviewed source admission is required before a record is available to the shared public projection.

Meld/Kair is a proposed consent-scoped session seam. The collaborator's current technical description is an assumption to confirm, not a live capability claim. A dedicated Adapter must preserve consent, pseudonymisation, retention, provenance and review before any public-safe contribution.

No single project does this alone. Their contracts meet at an eligibility-gated Public knowledge projection and a stable Topic/Case reference, not by merging identities, databases, or authority.

03

Standards

Where OParl, RIS and local news fit

OParl is an official-source interchange, while local reporting is editorial. Source-specific Adapters preserve that distinction and prepare reviewed records for the shared projection.

Reviewed public sources are one of three independent inbound seams into the Civic Journey.

The Adapter must preserve the exact source kind, identity, municipality, publication state, correction history and source owner. It may normalise an OParl payload or RIS export as an official_record, and separately capture permitted local reporting as an editorial_report; normalisation does not make either a new official system of record.

A human Reviewed source admission then decides whether that exact capture can enter a source-specific Reviewed source projection. Public Mecky can cite that projection without asking the administration to approve every generated sentence; source correction and withdrawal happen at the projection boundary.

Cross-municipality matching is a separate discovery projection. Similarity can suggest related Topics, but it cannot merge Cases, infer consent, or make one city's record authoritative for another.

04

Delivery

Why MCP is an Adapter, not the feed

The Model Context Protocol is useful for bounded agent reads. The initial interchange remains a replayable REST/cursor change feed, with Nostr as the signed public mirror.

One eligibility-gated Public knowledge projection feeds three bounded surfaces: REST/cursor for replay, MCP for agent reads, and Nostr for permanently public signed exchange.

The REST surface answers “what changed since this cursor?” with deterministic, bounded pages and explicit correction records. MCP can expose a Topic, reviewed source, Case projection, citation, or status explanation over the same version and digest.

MCP cannot admit a Case, attest a review, send an openDesk request, publish a Citizen Brief, start Mitmachen, cast a formal vote, sign a Safe transaction, or move treasury funds. Notifications may be added later as an optimization, but they must not create a second source of truth.

06

Scoping

Three build slices

Each slice is independently testable. The first closes the already-prioritized human journey; the later slices add Meld/Kair and interchange without delaying that browser proof.

Slice 01Civic Journey

Drive one Topic through Human Case admission, openDesk response, independent review, Citizen Brief, advisory Mitmachen, and reviewed outcome in staging. Formal governance and treasury remain separate institution-owned transitions.

Slice 02Meld/Kair boundary

Accept one synthetic consent-scoped bundle privately, derive one Reviewed deliberation artifact under human review, and prove correction and withdrawal without publishing private bundle identifiers.

Slice 03Change feed + agents

Serve deterministic content-minimal REST/cursor changes and bounded MCP reads over the same projection. Add Nostr only for artifacts that independently pass the permanent-public gate.

07

Before committing

Open questions

Worth resolving before accepting the integration contract or presenting a live capability.

Consent and identity

What exactly does a Meld/Kair session consent permit: retrieval, public exchange, Case citation, or only private review? A session pseudonym must not become a Röbel member identity without a separate link receipt.

Technical and licensing assumptions

Confirm the bundle wire format, capture location, models, retention/deletion, software and data licenses, and programme ownership with the collaborator before implementation.

Source legality and correction

For each OParl/RIS or local-news Adapter, confirm terms of use, source owner, capture rights, update cadence, withdrawal, and correction behavior.

Feed governance

Which actor can review, correct, withdraw, or publish a projection entry? The feed can be public and agent-readable without granting authority to a relay, MCP server, or model.

Cross-municipality discovery

Similarity must remain opt-in, public-safe discovery. It cannot merge Cases, copy session content, infer consent, or make another municipality's record authoritative.

08

Next step

Suggested next step

First complete and browser-prove the existing staging Topic → Human Case admission → openDesk return → Citizen Brief → advisory Mitmachen → reviewed outcome line.

Then add one synthetic consent-scoped Meld/Kair bundle and prove private review, public-safe derivation, correction, and withdrawal. Only after that should REST/cursor and bounded MCP expose the same projection digest; Nostr remains limited to independently permanent-public artifacts.

Three seams can meet. The conversation, source record and consent-scoped session can inform one Civic Journey without becoming one authority.
